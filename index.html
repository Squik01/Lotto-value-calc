How this is calculated

Each index is the expected pounds returned per £1 staked, counting only prize tiers of £20,000 or more. Jackpot tiers are discounted for the chance of a shared win, using a sales-vs-jackpot curve fitted (log-log regression) to whatever data points exist for that game. EuroMillions ships pre-loaded with two real data points (2019 rollover data and 2025-26 Superdraw figures). Lotto and Powerball start with no logged data — Lotto falls back to EuroMillions' curve as a rough stand-in, Powerball falls back to no discount at all (optimistic ceiling) until you log real sales figures for it, at which point the curve refits automatically and keeps improving as you add more points.

  • MARGINAL — above benchmark, but within a margin thin enough that the underlying assumptions could tip it either way.
  • PLAY — clearly ahead, with room for the assumptions to be somewhat wrong.
