How this is calculated

Each index is the expected pounds returned per £1 staked, counting only prize tiers of £20,000 or more. It's compared against a fixed benchmark: Set For Life, at 20.3p per £1 — the only one of these games with no jackpot to fluctuate, so it acts as the baseline everything else is measured against.

  • SKIP — below the 20.3p benchmark.
  • MARGINAL — above it, but within a margin thin enough that the underlying assumptions could tip it either way.
  • PLAY — clearly ahead, with room for the assumptions to be somewhat wrong.

Jackpot figures are pulled automatically twice a day from live results pages. Jackpot tiers are discounted for the chance of a shared win, using a sales-vs-jackpot curve — this needs real historical data on ticket sales, which isn't published live anywhere, so it's fixed rather than editable: EuroMillions uses two real data points (2019 rollover figures and 2025-26 Superdraw averages). Lotto has no historical dataset of its own, so it borrows EuroMillions' curve shape as a rough stand-in. Powerball is brand new in the UK with no sales history at all yet, so its estimate assumes no jackpot split — likely too generous once real data exists, which would make Powerball look somewhat worse than shown here.

Draw days: Lotto (Wed/Sat), EuroMillions (Tue/Fri — sets Millionaire Maker odds automatically), Powerball (results land Tue/Thu/Sun UK time, math is the same every draw). Always check live odds and prize breakdowns on national-lottery.co.uk before playing.
